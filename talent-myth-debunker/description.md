# talent-myth-debunker — 知乎文体描述

"我没有天赋"——这句话说出口的瞬间，一个人就获得了解脱：什么都不用做，命运替他做了决定。

《刻意练习》第八章把这些"天才"一个个拆开看：莫扎特的父亲是欧洲顶级音乐教师，4 岁起系统训练；帕格尼尼那段"即兴"独弦演奏，反复排练了 60 小时；跳高运动员的"零训练夺冠"，查下去发现他打了好几年篮球和橄榄球。

这个 skill 给你一套拆解动作：查训练史、查环境、查努力。拆完之后你会发现，所谓天赋，大多是"很早就开始的正确练习"。

基因决定你的起点，不决定你的上限。把"我没天赋"改写成"我还没用对方法练"，人生就从解释变成了行动。
