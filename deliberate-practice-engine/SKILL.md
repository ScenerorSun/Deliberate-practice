# 刻意练习引擎（Deliberate Practice Engine）

## R — 原文

> "刻意练习与其他类型的练习有几点不同。它需要人们付出最大限度的努力，它需要人们保持专注，它还发生在学习者的舒适区之外。刻意练习需要有定义明确的具体目标，需要有即时的反馈……"

> — 安德斯·艾利克森，《刻意练习》第4章

---

## I — 方法论骨架

刻意练习 = 有目的练习（具体目标 + 专注 + 反馈 + 走出舒适区）+ 两个硬条件（领域成熟 + 导师指导）。判断一次练习是不是"刻意"，看四个问题：我练的是不是能力边界上的事？有没有明确的改进目标？练完能不能立刻知道对错？有没有人（或替代物）告诉我盲区？四个都是"是"，才是刻意练习；缺任何一个，都只是变相的重复。

## A1 — 书中的应用

### 案例 1: 小提琴家练习时长研究
- **问题**: 为什么同样的练习时长，有人成为独奏家，有人停滞在平庸水平
- **方法论的使用**: 艾利克森对比杰出与普通小提琴家的练习记录，发现差距不在总量，而在"有目的的练习"的占比
- **结论**: 杰出者把大部分时间花在刻意练习上，普通人把大部分时间花在自动化重复上
- **结果**: 同一万小时，两种练法，两种水平

### 案例 2: 史蒂夫的数字记忆
- **问题**: 普通人的记忆上限似乎只有 7±2 位数字
- **方法论的使用**: 用刻意练习的标准设计训练（目标+专注+反馈+挑战）
- **结果**: 练到 82 位，远超"人类极限"

## A2 — 触发场景

### 用户会在什么情境下需要这个 skill?

1. 学习/练习新技能（语言、乐器、编程、写作）几个月后感觉没有实质进步
2. 准备考试或面试，想知道自己刷题/背书的练习方式是否高效
3. 想评估自己当前的工作日常（开会、写报告、写代码）里哪些算练习、哪些只是表演

### 语言信号

- "我练了很久但感觉没进步"
- "这样练到底有没有用"
- "怎么才能进步更快"
- "把这段练习安排诊断一下"

### 与相邻 skill 的区分

- 与 `comfort-zone-calibration` 的区别：本 skill 做全面诊断（四要素），comfort 专注"挑战度"这一个维度
- 与 `plateau-breakthrough` 的区别：本 skill 诊断练习性质，plateau 处理已经确诊的停滞期

## E — 可执行步骤

当 skill 被激活后，agent 应按以下步骤执行：

1. **采集练习现状**
   - 完成标准: 拿到用户练什么、多久、每次怎么练、有无反馈、有无目标的具体描述

2. **按四要素逐项诊断**
   - 目标: 具体可测量吗？还是"练好""变强"这种模糊词？
   - 专注: 练习时是否高度投入？还是边听歌边机械重复？
   - 反馈: 练完能否立刻知道对错？有没有镜子/录像/数据/导师？
   - 挑战: 练的是舒适区内还是边界外？
   - 完成标准: 每项给出"是/否/部分"判定

3. **输出升级处方**
   - 针对每项缺失给出 1 个最小可执行的改进动作（如：把"练口语"改成"录一段30秒对话，找出3个卡顿点"）
   - 判停条件: 若用户只是倾诉情绪而非要改进方案，先共情再给方案

## B — 边界

### 不要在以下情况使用此 skill

- 用户问的是具体知识点（"什么是心理表征"）——那是信息查询
- 用户处于强烈情绪中，需要的是倾听而非诊断

### 作者在书中警告的失败模式

- 天真练习：重复已掌握动作，误以为在进步（第1章）

### 作者的盲点 / 时代局限

- 刻意练习依赖"成熟领域"（有客观标准+导师传统）；管理、创作等模糊领域只能逼近，不能完全套用

### 容易混淆的邻近方法论

- 一万小时定律：只强调时长，忽略质量——本 skill 明确反对以时长论英雄
