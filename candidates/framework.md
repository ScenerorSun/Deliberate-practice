# 框架提取器 — 候选框架单元

## F1. 刻意练习的黄金标准（四要素）
- 成熟领域（有客观标准+训练传统）
- 优秀导师（已建立心理表征的人）
- 持续挑战（舒适区之外）
- 即时反馈（可执行的修正信息）

## F2. 三种练习的层级
天真练习 → 有目的练习（目标/专注/反馈/出舒适区）→ 刻意练习（+领域成熟+导师）

## F3. 有目的练习四要素
1. 明确的具体目标（可测量）
2. 高度专注（不能自动驾驶）
3. 即时反馈（知道自己错在哪）
4. 走出舒适区（身体收到改变信号）

## F4. 成为杰出人物的四阶段路线图
产生兴趣 → 变得认真 → 全力投入 → 开拓创新

## F5. 心理表征的功能五分类
找规律 / 解释信息 / 组织信息 / 制订计划 / 高效学习

## F6. 瓶颈突破三步
停下来解剖样本 → 找共同结构 → 带着结构练（换方式而非更用力）

## F7. 王牌训练法（工作应用）
把高风险错误转移到训练场；训练要模仿真实场景并即时评分

## F8. 保持动机的双层结构
外部动机（社交认可/经济回报）→ 内部动机（身份认同："我是一个跑者"）

## F9. 停滞期应对
平台期=心理表征需要升级的信号；换策略、增加挑战、寻求新反馈

## F10. 专注力预算
新手每天有效刻意练习约1小时，专家上限约4小时；超出无效
